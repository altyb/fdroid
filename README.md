# Nile Birds F-Droid repo

Shoebill (video player) and Hudhud Keyboard, with updates through the F-Droid app. These are the same signed APKs as the GitHub releases.

Add it in F-Droid under Settings, Repositories, then +:

```
https://altyb.github.io/fdroid/repo?fingerprint=4882F491E55FA2B5630EBA1409087C2DC2F404E8786813D0E60B13569CC1040A
```

This is my own repo, not the main F-Droid catalogue, so F-Droid does not build or review these apps.

Source: [Shoebill](https://github.com/altyb/shoebill), [Hudhud](https://github.com/altyb/hudhud).
